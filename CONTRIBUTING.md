# Contributing

This project is currently private and under active design and implementation by Sudhish Singh.

## Engineering Rules

- Build from scratch.
- Do not use orchestration frameworks in core implementation.
- Keep core abstractions framework-independent.
- Add owner and SPDX headers to every source and documentation file.
- Write scalable, memory-conscious, negative-case-first code.
- Do not commit secrets, credentials, private data, or real hospital/patient data.
