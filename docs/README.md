# Documentation

This directory contains architecture, design decisions, threat models, governance notes, security documentation, examples, and interview preparation notes for the Agent Local LLM Hybrid Framework.

## Sections

- `adr/` - Architecture Decision Records
- `architecture/` - Framework architecture and subsystem design
- `threat_model/` - Threat modeling and risk analysis
- `security/` - Security design and data protection notes
- `governance/` - AI governance, Responsible AI, and compliance readiness
- `evaluation/` - Evaluation design and metrics documentation
- `examples/` - Usage examples and solution assembly guides
- `interview_notes/` - Architect-level interview preparation notes
