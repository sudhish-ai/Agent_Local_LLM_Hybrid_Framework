# Security Policy

This project is being developed as a from-scratch RAG and Agentic AI framework with a security-first design.

## Security Principles

- No secrets should be committed to the repository.
- No real patient data, PHI, hospital records, or private enterprise documents should be committed.
- Access control must be enforced before retrieved context reaches generation.
- Prompt injection risks must be treated as first-class security concerns.
- Sensitive data leakage must be tested through negative and security test cases.

## Reporting Security Issues

While this repository is private, security issues should be tracked privately by the owner.
